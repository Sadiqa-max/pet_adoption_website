## Project Overview
* **Theme:** Pet Adoption Portal
* **Description:** A pastel-themed interactive web platform designed to let users explore adoptable pets, view individual profile details, and fill out an adoption application or schedule a shelter visit.

1. `index.html` - Homepage featuring hero banner, pet categories, and interactive pet grid.
2. `pet-detail.html` - Detail view displaying specific pet bio, stats, and action options.
3. `adoption-form.html` - Application form for adopting a pet or scheduling a visit.
